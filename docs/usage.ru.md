# REAL — инструкция

[English version](usage.en.md) · [Описание настроек](settings.ru.md)

REAL (REduce Audio Latency) снижает задержку звука в Windows 10 и 11 сразу для всех программ:
игр, музыкальных программ, браузеров, звонков. Здесь описано, что делает программа, как её
установить и как ею пользоваться.

## 1. Что делает REAL

По умолчанию звуковой движок Windows смешивает звук порциями (буферами) по 10 мс. Если
какая-то программа просит буфер меньше, движок использует его для всех программ, которые
играют через то же устройство. REAL держит открытым такой поток с минимальным буфером,
который поддерживает драйвер устройства, поэтому задержка снижается сразу для всех программ.
Обычно это буфер 2–3 мс вместо 10 мс.

* REAL не обрабатывает звук и не меняет настройки системы: он только держит поток открытым.
  Как только REAL завершается, Windows возвращается к своему буферу.
* Обрабатываются устройства по умолчанию. В Windows у каждого направления их два —
  устройство по умолчанию и устройство связи по умолчанию («Параметры → Система → Звук»);
  REAL обрабатывает оба, а устройство с обеими ролями — один раз.
* По умолчанию обрабатываются устройства воспроизведения; устройства записи можно добавить
  в настройках.
* Вместо минимального буфера можно выбрать фиксированный размер (см. [Настройки](#5-настройки)).

Побочные эффекты:

* Маленький буфер приходится заполнять чаще. При большой нагрузке на процессор растёт риск
  треска. Если он появился, выберите фиксированный буфер больше минимального.
* Пока такой поток работает, Windows может зарезервировать одно ядро процессора для звука:
  другие программы получают его в последнюю очередь, и в мониторинге оно выглядит
  недогруженным. Это режим низкой задержки самой Windows; такое ядро показывает строка
  «Процессор» отчёта диагностики.
* Процессор просыпается чаще, поэтому ноутбук работает от батареи немного меньше.
* Приоритет процесса REAL ни на что из этого не влияет: звук обрабатывает служба
  Windows Audio, а не REAL.

## 2. Установка

1. Скачайте `REAL.exe` со страницы
   [последнего релиза](https://github.com/Mutaracha/REAL/releases/latest). Устанавливать
   ничего не нужно, Visual C++ Redistributable тоже не нужен. Требования: Windows 10 или
   Windows 11, 64-битная.
2. Положите `REAL.exe` в отдельную папку, в которую у вас есть право записи, например
   `C:\Tools\REAL`. REAL хранит рядом с собой файл настроек `real.settings.json`, а по вашему
   запросу — файл журнала и отчёт диагностики. Не используйте `C:\Program Files`: там
   настройки не сохранятся.
3. Запустите `REAL.exe`. Файл не подписан, поэтому фильтр SmartScreen может показать окно
   «Система Windows защитила ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом
   случае». Браузер тоже может предупредить, что файл скачивают редко.
4. Строка состояния внизу окна показывает текущий буфер, например
   `2,67 мс - Динамики (Realtek(R) Audio)`. Если там написано, что драйвер уже отдаёт
   минимальный буфер, см. [Ограничения](#11-ограничения) и следующий раздел.
5. Чтобы REAL запускался вместе с Windows, включите «Опции → Запускать с Windows».

Задержка остаётся низкой, пока REAL работает; окно можно спрятать в трей.

### Стандартный драйвер Windows (рекомендуется)

Драйверы производителей звуковых карт часто не предлагают буфер меньше 10 мс. Стандартный
драйвер Windows для встроенного звука обычно поддерживает буферы меньше:

1. Откройте «Диспетчер устройств».
2. В разделе «Звуковые, игровые и видеоустройства» дважды щёлкните устройство ваших динамиков.
3. На вкладке «Драйвер» нажмите «Обновить драйвер» → «Найти драйверы на этом компьютере»
   (в Windows 10 — «Выполнить поиск драйверов на этом компьютере») → «Выбрать драйвер из
   списка доступных драйверов на компьютере».
4. Выберите «Устройство с поддержкой High Definition Audio» и нажмите «Далее». Если его нет в
   списке, снимите флажок «Только совместимые устройства».
5. Перезагрузите компьютер, если Windows попросит.

> **Осторожно:** после смены драйвера громкость может стать неприятно высокой. Чтобы вернуть
> прежний драйвер, выберите его тем же способом.

## 3. Окно программы

В главном окне — журнал: что делает REAL — запуск, файл настроек, устройства, перезапуски и
ошибки. Журнал в окне показывает основные события независимо от настроек файла журнала.

Строка состояния внизу показывает текущее состояние:

| Строка состояния | Что значит |
|---|---|
| `2,67 мс - Динамики (Realtek(R) Audio)` | Буфер, с которым сейчас работает звуковой движок, и устройство. `(+1 ещё)` — обрабатывается ещё одно устройство |
| `… (буфер задан другим приложением)` | Буфер уже задала другая программа, REAL использует его (см. [Ограничения](#11-ограничения)) |
| `драйвер уже отдаёт минимальный буфер (10,00 мс) - …` | Драйвер устройства не умеет буфер меньше, REAL не держит на нём поток |
| `Снижение задержки выключено` | Выключено в меню |
| `отключено: устройство не отвечает` | Устройство не ответило вовремя (см. [Автоматический перезапуск](#6-автоматический-перезапуск)) |
| `Снижение задержки не активно` | Ничего не применено, например нет устройства по умолчанию |

Строка меню:

* «REAL»: «REAL запущен» — галочка включает и выключает снижение задержки; «Перезапустить» —
  аудиопотоки создаются заново; «Выход».
* «Опции»: «Настройки» — окно настроек; «Запускать с Windows».
* «Диагностика»: «Диагностика» — отчёт об аудиоустройствах (см.
  [раздел 10](#10-диагностика-и-сообщение-о-проблеме)); «Открыть журнал» — файл журнала, если он
  включён.
* «О программе»: версия, путь к файлу настроек и ссылки на проект и на эту документацию.

Кнопки окна:

* «Свернуть» прячет окно в трей (настройка «Сворачивать в трей»).
* Крестик завершает REAL. С настройкой «Кнопка закрытия: Свернуть в трей» он прячет окно.
* Без значка в трее окну некуда прятаться: «Свернуть» сворачивает его на панель задач, крестик
  всегда завершает программу.

Копия REAL всегда одна. Повторный запуск `REAL.exe` показывает окно уже работающей копии.

## 4. Значок в трее

* Левый щелчок показывает или прячет окно, правый открывает меню.
* Подсказка показывает состояние: `REAL - 2,67 мс - Динамики (Realtek(R) Audio)`.
* Меню: строка состояния, «REAL запущен», «Перезапустить» — «Файл журнала», «Диагностика» —
  «Настройки» — «Выход». «Файл журнала» и «Диагностика» по умолчанию скрыты (они есть в строке
  меню окна); пункты можно показать или скрыть в настройках, а строка состояния, «Настройки» и
  «Выход» есть всегда.
* Значок возвращается после перезапуска Проводника.

## 5. Настройки

«Опции → Настройки» (или «Настройки» в меню значка) открывает окно «Настройки REAL» с тремя
вкладками:

* «Окно» — язык, запуск, кнопки окна, значок в трее и его меню, уведомления;
* «Звук» — устройства, буфер, автоматический перезапуск;
* «Прочее» — приоритет процесса, проверка обновлений, файл журнала, файл настроек.

«Сохранить» записывает файл настроек и сразу применяет значения, ничего перезапускать не
нужно. «Отмена» (или Esc) закрывает окно без изменений. Если задержать указатель на настройке,
всплывает короткое описание. Значения проверяются по «Сохранить»: неподходящее значение
возвращается прежним, окно открывает вкладку этого поля, а подсказка рядом с ним называет,
что поле принимает.

Настройки хранятся в `real.settings.json` рядом с `REAL.exe`. Окно и файл — одно и то же: что
сохранило окно, то и лежит в файле, с комментарием у каждого значения. Файл можно править и
вручную: «Прочее → Файл настроек → Открыть» открывает его в редакторе, «Перечитать» заново
читает его в окно. Щелчок по пути копирует путь к папке. Каждая настройка описана в
[описании настроек](settings.ru.md).

«Язык» (вкладка «Окно»): «Как в Windows», «English» или «Русский». Окно настроек переходит на
выбранный язык сразу, остальная программа и комментарии в файле — после «Сохранить».
«Как в Windows» даёт русский для русской, украинской и белорусской Windows, иначе английский.

## 6. Автоматический перезапуск

REAL сам создаёт аудиопотоки заново, без перезапуска программы (вкладка «Звук», группа
«Автоматический перезапуск»):

* «Смена устройства по умолчанию» — устройством по умолчанию или устройством связи по
  умолчанию стало другое устройство. Так же Windows сообщает, что устройство по умолчанию
  отключили или подключили обратно. Другие устройства перезапуска не вызывают: микрофон, когда
  обрабатывается воспроизведение, звук монитора, который засыпает, наушники, которые не стали
  устройством по умолчанию.
* «Выход из спящего режима», включая Modern Standby.
* «Разблокировка сеанса» (после Win+L).
* Кроме того, раз в 30 секунд REAL проверяет, что поток жив и устройство по умолчанию то же
  самое.

На одно изменение Windows присылает пачку событий, поэтому REAL ждёт «Пауза перед
перезапуском, с» (по умолчанию 1 с) после последнего.

Если устройство не отвечает, REAL повторяет попытку через 2, 4, 8 … до 30 секунд. Через
«Ждать ответа устройства, с» (по умолчанию 60 с) он выключает снижение задержки и перестаёт
опрашивать устройство; в строке состояния — `отключено: устройство не отвечает`. Следующая
смена устройства по умолчанию снова его включает.

Если устройства по умолчанию нет совсем (например, сразу после запуска Windows звук ещё не
готов), в журнале — `Аудиоустройство по умолчанию не подключено.` Как только устройство
появится, снижение задержки применится само.

Смена устройства по умолчанию включает снижение задержки, даже если оно было выключено —
вами или потому, что устройство не отвечало.

«Перезапустить» в меню (или `REAL.exe --reinit`) делает то же самое вручную и включает снижение
задержки, если оно было выключено.

## 7. Уведомления

Уведомления приходят без звука и только когда окно скрыто в трее или свёрнуто: пока оно
открыто, то же самое видно в журнале. Каждый вид можно выключить в настройках (вкладка
«Окно», группа «Уведомления»):

* «Уведомлять об ошибках» — устройство по умолчанию перестало отвечать: одно уведомление на
  сбой, а не на каждую попытку, и одно — когда звук снова работает. Отсутствие устройства —
  не ошибка: только строка в журнале.
* «Уведомлять о смене устройства по умолчанию» — Windows сменила устройство по умолчанию, и
  REAL перезапустил потоки на новом.
* «Уведомлять о включении и выключении» — снижение задержки включили или выключили в меню,
  оно само включилось при смене устройства по умолчанию или его перезапустили через
  «Перезапустить».

У некоторых уведомлений настройки нет: найденная при запуске новая версия (щелчок открывает
страницу релиза), файл настроек, который не удалось прочитать, и ответы на команды меню
(например, «Файл журнала», когда файл журнала выключен).

## 8. Обновления

* REAL проверяет новую версию один раз при запуске — одним запросом к
  `github.com/Mutaracha/REAL/releases/latest`. Во время работы запросов нет.
* «Прочее → Обновления → Проверять при запуске» выключает проверку: тогда REAL не делает ни
  одного сетевого запроса.
* Новая версия появляется строкой в журнале — `Доступна версия REAL v1.0.1 (…)` — и, если окно
  скрыто, уведомлением. Щелчок по уведомлению открывает страницу релиза. Ничего не скачивается
  и не устанавливается, REAL ради обновления никогда не закрывается.
* Проверка, которая не нашла ничего нового или не удалась из-за отсутствия сети, пишется только
  в файл журнала.

Чтобы обновиться, завершите REAL и замените `REAL.exe` новым. Настройки сохранятся.

## 9. Командная строка

| Ключ | Что делает |
|---|---|
| *(без ключей)* | Запуск с окном (и значком в трее, если он включён) |
| `--tray` | Стартовать свёрнутым в трей |
| `--no-tray` | Стартовать с видимым окном |
| `--config <путь>` | Использовать другой файл настроек вместо `real.settings.json` |
| `--no-config` | Не читать файл настроек, взять встроенные значения |
| `--log-level <уровень>` | Уровень файла журнала: `off`, `error`, `warn`, `info`, `debug`, `trace` |

`--tray`, `--no-tray` и `--log-level` действуют только на этот запуск и в файл настроек не
записываются.

Команды для работающей копии: команда передаётся ей, а новый процесс завершается.

| Ключ | Что делает |
|---|---|
| `--reinit` | Перезапустить: заново создать аудиопотоки; снижение задержки включается |
| `--enable` | Включить снижение задержки |
| `--disable` | Выключить снижение задержки |
| `--exit` | Закрыть работающую копию |

Команды, которые выполняются сами по себе:

| Ключ | Что делает |
|---|---|
| `--diagnose` | Записать отчёт об аудиоустройствах в `REAL-diagnostics.txt` |
| `--help`, `-h`, `/?` | Показать справку |
| `--version` | Показать версию |

Регистр ключей не важен. О неизвестном ключе пишется строка в журнал, ключ игнорируется.
При запуске из командной строки `--help`, `--version` и `--diagnose` выводят текст туда же;
иначе текст показывается в окне сообщения (отчёт открывается в текстовом редакторе).

## 10. Диагностика и сообщение о проблеме

«Диагностика → Диагностика» в строке меню (или `REAL.exe --diagnose`) записывает
`REAL-diagnostics.txt` рядом с `REAL.exe` и открывает его. Если папка только для чтения, отчёт
пишется во временную папку (`%TEMP%`). В отчёте:

* версии REAL и Windows, масштаб интерфейса, ядра процессора и ядра, которые Windows
  зарезервировала для звука;
* действующие настройки;
* каждое активное устройство выбранного в настройках направления: драйвер и его версия,
  формат и размеры буфера, которые поддерживает устройство, — стандартный, минимальный,
  базовый шаг и максимальный — и итог: можно ли снизить задержку на этом устройстве.

Файл журнала по умолчанию выключен. Чтобы разобраться в проблеме:

1. «Опции → Настройки → Прочее → Журнал → Уровень»: выберите «Подробно (debug)» и нажмите
   «Сохранить».
2. Повторите проблему.
3. «Диагностика → Открыть журнал» открывает `REAL.log`.
4. Потом верните уровень «Выключен (off)».

Чтобы сообщить о проблеме, создайте [issue](https://github.com/Mutaracha/REAL/issues) и
приложите `REAL-diagnostics.txt` и, если есть, `REAL.log`. Укажите версию REAL (окно «О
программе» или `REAL.exe --version`), версию Windows и что произошло. Писать можно по-русски.
В отчёте есть названия ваших аудиоустройств и пути к `REAL.exe` и файлу настроек (в них может
быть имя пользователя); уберите то, чем не хотите делиться.

По версии видно, какая у вас сборка: релиз показывает `v1.0.0`, тестовая сборка из GitHub
Actions — `v1.0.0 RC 71 (0f7eb3a)`: номер сборки и коммит, из которого она сделана.

## 11. Ограничения

* **Всё решает драйвер.** Bluetooth (10 мс по замыслу), приёмники HDMI и DisplayPort,
  виртуальные устройства и некоторые драйверы производителей не предлагают буфер меньше
  стандартного. На таком устройстве REAL не держит поток, а в строке состояния —
  `драйвер уже отдаёт минимальный буфер (10,00 мс) - …`. Для встроенного звука часто помогает
  стандартный драйвер Windows (см. [раздел 2](#стандартный-драйвер-windows-рекомендуется)).
* **Буфер может быть уже занят.** Если буфер движка уже задала другая программа (игра,
  музыкальная программа), Windows не даёт его менять, пока та работает. REAL тогда использует
  этот буфер, а строка состояния добавляет `(буфер задан другим приложением)`. Когда та
  программа закроется, «Перезапустить» вернёт буфер REAL.
* **Только устройства по умолчанию.** Программа, которая играет через другое устройство,
  задержку не снижает.
* **Только пока REAL работает.** REAL ничего не меняет насовсем: после выхода буфер
  становится прежним.
* **Windows 10 или 11, 64-битная.** Интерфейс — на русском или английском.

## 12. Удаление

1. Выключите «Опции → Запускать с Windows»: так удалится запись автозапуска `REAL` (в
   `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`).
2. Завершите REAL: «REAL → Выход» или «Выход» в меню значка.
3. Удалите папку с `REAL.exe`. Кроме программы, в ней могут быть `real.settings.json`,
   `REAL.log` с прежними файлами (`REAL.1.log` …), `REAL-diagnostics.txt` и
   `real.settings.json.bak` или `.bad`. Отчёт, записанный в `%TEMP%`, остаётся там.

Больше REAL ничего не устанавливает: ни служб, ни драйверов, ни других записей реестра.
Стандартный драйвер Windows, если вы его поставили, остаётся; чтобы вернуть прежний, выберите
его в «Диспетчере устройств».
