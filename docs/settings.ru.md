## 1. Файл настроек

* `real.settings.json` лежит рядом с `REAL.exe` и создаётся при первом запуске со значениями
  по умолчанию. Путь к нему показывает окно «О программе». Чтобы вернуть значения по
  умолчанию, завершите REAL и удалите файл: следующий запуск создаст его заново.
* Формат — JSON с комментариями: `//` и `/* */` разрешены, кодировка UTF-8 (BOM допускается).
  Запятая после последнего элемента списка или объекта не допускается.
* У каждого значения в той же строке есть комментарий на языке интерфейса; первые строки файла
  ссылаются на эту страницу.
* Окно настроек («Опции → Настройки») правит этот же файл: что сохранило окно, то и лежит в
  файле. При запуске REAL перезаписывает файл, только если сменился язык его комментариев или
  его оформление (см. [Служебные поля](#10-служебные-поля)), поэтому ваши правки остаются как
  есть. Сохранение из окна записывает файл заново: ваши собственные комментарии и неизвестные
  ключи не сохраняются.
* Файл записывается через временный, поэтому прерванная запись не оставляет обрезанного файла.
* После ручной правки запустите REAL заново или нажмите «Перечитать» в окне настроек (вкладка
  «Прочее», группа «Файл настроек»), а затем «Сохранить». «Открыть» в той же группе открывает
  файл в редакторе.

Откуда берутся значения, по убыванию приоритета:

```
командная строка  >  real.settings.json  >  встроенные значения по умолчанию
```

* `--config <путь>` читает и записывает другой файл вместо `real.settings.json`.
* `--no-config` не читает файл: используются встроенные значения.
* `--tray`, `--no-tray` и `--log-level` действуют на один запуск и в файл не записываются.

## 2. Если файл не подходит

| Что случилось | Что делает REAL |
|---|---|
| Файла нет | Создаёт его со значениями по умолчанию |
| Файл не разбирается (лишняя запятая, пропущенная кавычка) | Работает на значениях по умолчанию и файл не меняет. Журнал называет причину, например место ошибки; одно уведомление, если окно скрыто. При сохранении настроек прежний текст остаётся рядом — `real.settings.json.bad` |
| Значение не подходит: не тот тип, число вне диапазона, неизвестное слово | Значение не применяется: остаётся последнее используемое — при запуске значение по умолчанию, после «Перечитать» — действующее. Журнал называет ключ, причину и значение, которое используется: `audio.reinit.debounceSec: значение 70 вне диапазона 1–60; используется 1` |
| Неизвестный ключ | Пропускается со строкой в журнале: `application.example: неизвестный параметр, игнорируется`. При следующем сохранении исчезает |
| Файл больше 100 КБ | Это не файл настроек, он не читается. При запуске он переименовывается в `real.settings.json.bak` (прежний `.bak` заменяется), а на его месте создаётся новый файл со значениями по умолчанию; в журнале — строка об этом |
| Файл больше 100 КБ и только для чтения | Не трогается: REAL работает на значениях по умолчанию, а сохранить настройки не получится, пока файл больше 100 КБ |

Проверка на 100 КБ выполняется и перед каждой записью файла: сохранение настроек, «Запускать с
Windows», перевод комментариев. «Перечитать» в окне настроек файл не переименовывает, а только
называет причину.

Окно настроек проверяет значения по «Сохранить», с теми же пределами, что и чтение файла:
значение, которое приняло окно, не будет отброшено при следующем запуске.

## 3. Язык

`application.language` задаёт язык всего сразу: интерфейса, журнала, файла журнала,
уведомлений и комментариев в файле настроек.

* `"auto"` (по умолчанию) — язык Windows: русский, украинский и белорусский дают русский,
  любой другой язык — английский;
* `"en"` — английский, `"ru"` — русский.

Регистр не важен; понимаются и `"english"`, `"russian"`.

Когда язык меняется, файл один раз перезаписывается с комментариями на новом языке, все
значения сохраняются: после «Сохранить» в окне настроек или при следующем запуске после ручной
правки. С `"auto"` то же происходит при смене языка Windows. Само окно настроек переходит на
выбранный язык сразу; остальная программа — после «Сохранить», «Отмена» оставляет прежний язык.

## 4. application

Вкладка «Окно», группа «Приложение».

| Ключ | В окне | Значения | По умолчанию | Что делает |
|---|---|---|---|---|
| `language` | «Язык» | `"auto"` («Как в Windows»), `"en"` («English»), `"ru"` («Русский») | `"auto"` | Язык программы и комментариев в этом файле, см. [Язык](#3-язык) |
| `startWithWindows` | «Запускать с Windows» | `true`, `false` | `false` | REAL запускается при входе в Windows: запись `REAL` в `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`. То же, что «Опции → Запускать с Windows» в меню |
| `startMinimizedToTray` | «Запускать свёрнутым в трей» | `true`, `false` | `false` | При запуске окно не открывается, REAL сразу работает в трее — как с `--tray` |
| `minimizeToTray` | «Сворачивать в трей» | `true`, `false` | `true` | Кнопка «Свернуть» прячет окно в трей, а не на панель задач |
| `closeButtonAction` | «Кнопка закрытия» | `"exit"` («Завершить программу»), `"minimize"` («Свернуть в трей») | `"exit"` | Что делает крестик окна |

Последним трём нужен значок в трее. Без него они в окне серые и не действуют: окно при запуске
видно, «Свернуть» сворачивает его на панель задач, крестик завершает программу.

Запись автозапуска следует за файлом: REAL при запуске создаёт её, исправляет (например, если
папку перенесли) или удаляет.

## 5. tray

Вкладка «Окно», группы «Значок в трее» и «Уведомления».

| Ключ | В окне | Значения | По умолчанию | Что делает |
|---|---|---|---|---|
| `enabled` | «Показывать значок в трее» | `true`, `false` | `true` | Значок в области уведомлений: левый щелчок показывает или прячет окно, правый открывает меню |
| `menu.toggleEnabled` | «Пункты меню значка:» «REAL запущен» | `true`, `false` | `true` | Пункт меню, который включает и выключает снижение задержки |
| `menu.reinitialize` | «Пункты меню значка:» «Перезапустить» | `true`, `false` | `true` | Пункт меню, который заново создаёт аудиопотоки |
| `menu.openLog` | «Пункты меню значка:» «Файл журнала» | `true`, `false` | `false` | Пункт меню, который открывает файл журнала |
| `menu.diagnostics` | «Пункты меню значка:» «Диагностика» | `true`, `false` | `false` | Пункт меню, который записывает отчёт диагностики |
| `notifications.onError` | «Уведомлять об ошибках» | `true`, `false` | `true` | Устройство по умолчанию перестало отвечать: одно уведомление на сбой, а не на каждую попытку, и одно — когда звук снова работает |
| `notifications.onDeviceChange` | «Уведомлять о смене устройства по умолчанию» | `true`, `false` | `true` | Windows сменила устройство по умолчанию, и REAL перезапустил аудиопотоки на новом |
| `notifications.onStateChange` | «Уведомлять о включении и выключении» | `true`, `false` | `true` | Снижение задержки включили или выключили в меню, оно само включилось при смене устройства по умолчанию или его перезапустили через «Перезапустить» |

* Строка состояния, «Настройки» и «Выход» есть в меню значка всегда. «Файл журнала» и
  «Диагностика» есть и в строке меню окна.
* Уведомления приходят без звука и только когда окно скрыто в трее или свёрнуто. Запуск REAL и
  перезапуски после сна и разблокировки уведомлений о состоянии не дают; отсутствие устройства
  по умолчанию — тоже не ошибка, только строка в журнале.
* Без значка в трее пункты меню и уведомления в окне серые: их показывает значок.

## 6. audio

Вкладка «Звук», группы «Аудиопотоки» (первые три ключа) и «Автоматический перезапуск» (ключи
`audio.reinit`).

| Ключ | В окне | Значения | По умолчанию | Что делает |
|---|---|---|---|---|
| `dataFlow` | «Устройства» | `"render"` («Воспроизведение»), `"capture"` («Запись»), `"both"` («Воспроизведение и запись») | `"render"` | Для каких устройств по умолчанию снижать задержку. В каждом направлении обрабатываются все устройства по умолчанию, включая устройство связи |
| `buffer` | «Буфер» | `"min"` («Минимальный»), `"fixed"` («Фиксированный») | `"min"` | Минимальный буфер, который поддерживает драйвер, или размер из `fixedBufferFrames` |
| `fixedBufferFrames` | «Фиксированный буфер, фреймы» | 0–100000 | `0` | Размер фиксированного буфера во фреймах, только для `"fixed"`; 0 — не задан |
| `reinit.defaultDeviceChanged` | «Смена устройства по умолчанию» | `true`, `false` | `true` | Перезапуск, когда устройством по умолчанию или устройством связи по умолчанию становится другое устройство; так же Windows сообщает, что устройство по умолчанию отключили или подключили обратно |
| `reinit.resumeFromSleep` | «Выход из спящего режима» | `true`, `false` | `true` | Перезапуск после сна или Modern Standby |
| `reinit.sessionUnlock` | «Разблокировка сеанса» | `true`, `false` | `true` | Перезапуск после разблокировки сеанса (Win+L) |
| `reinit.failureTimeoutSec` | «Ждать ответа устройства, с» | 5–300 | `60` | Сколько повторять попытки, если устройство не отвечает; потом снижение задержки выключается, а устройство больше не опрашивается |
| `reinit.debounceSec` | «Пауза перед перезапуском, с» | 1–60 | `1` | На одно изменение Windows присылает пачку событий: перезапуск ждёт столько после последнего |

Как устроен перезапуск — повторные попытки, проверка раз в 30 секунд, что снова включает
снижение задержки — описано в [инструкции](usage.ru.md#6-автоматический-перезапуск).

### Буфер

Буфер звукового движка измеряется во фреймах: фрейм — один отсчёт звука по всем каналам, при
48 000 Гц 480 фреймов — это 10 мс. Чем меньше фреймов, тем ниже задержка.

Драйвер сообщает, какие буферы он поддерживает: стандартный, минимальный, базовый шаг и
максимальный. Их показывает отчёт диагностики, а окно настроек показывает диапазон устройства
по умолчанию под названием поля, например `Допустимо: 144–480, шаг 48 (3,00–10,00 мс)`.
Фиксированный буфер должен лежать между минимальным и максимальным и быть кратным шагу. Базовый
шаг — это не размер буфера: он может быть меньше минимального (даже 1 фрейм), а REAL никогда
не просит буфер меньше минимального.

* Окно принимает только значение, которое подходит текущему устройству по умолчанию. Пока
  устройство ни разу не запускалось и его диапазон неизвестен, окно проверяет только, что это
  целое число от 1 до 100000. Если выбрать «Фиксированный» при пустом поле, в него
  подставляется буфер, с которым устройство работает сейчас.
* Значение из файла, которое устройство не принимает (файл правили вручную или устройство
  сменилось), подгоняется — округляется вниз до шага и удерживается в диапазоне, — а журнал
  один раз пишет об этом: `Фиксированный буфер 500 фреймов не подходит устройству «Динамики»
  (144–480, шаг 48), используется 480 фреймов.`
* `"fixed"` при `fixedBufferFrames: 0` даёт предупреждение при чтении файла, и берётся
  минимальный буфер.

## 7. performance

Вкладка «Прочее», группа «Процесс REAL».

| Ключ | В окне | Значения | По умолчанию | Что делает |
|---|---|---|---|---|
| `processPriority` | «Приоритет процесса» | `"idle"` («Низкий»), `"belowNormal"` («Ниже среднего»), `"normal"` («Обычный») | `"idle"` | Приоритет процесса REAL, как в диспетчере задач |

Приоритет не влияет на звук: звук обрабатывает служба Windows Audio, а REAL только держит поток
и ждёт событий. По той же причине Windows 11 всегда считает процесс REAL экономным (EcoQoS), без
настройки.

## 8. updates

Вкладка «Прочее», группа «Обновления».

| Ключ | В окне | Значения | По умолчанию | Что делает |
|---|---|---|---|---|
| `checkOnStartup` | «Проверять при запуске» | `true`, `false` | `true` | Одна проверка новой версии при запуске; `false` — ни одного сетевого запроса |

Релизы читаются из репозитория проекта, он зашит в программу. Во время работы проверок нет,
ничего не скачивается и не устанавливается. Подробнее — в [инструкции](usage.ru.md#8-обновления).

## 9. logging

Вкладка «Прочее», группа «Журнал». Раздел описывает только файл журнала: журнал в окне всегда
показывает основные события, какой бы уровень ни был у файла.

| Ключ | В окне | Значения | По умолчанию | Что делает |
|---|---|---|---|---|
| `level` | «Уровень» | `"off"` («Выключен (off)»), `"error"` («Ошибки (error)»), `"warn"` («Предупреждения (warn)»), `"info"` («Основное (info)»), `"debug"` («Подробно (debug)»), `"trace"` («Всё (trace)») | `"off"` | `off` — файл журнала не ведётся совсем; остальные уровни пишут файл, от самого краткого к самому подробному. Понимаются и `none`, `err`, `warning` |
| `filePath` | «Путь к файлу» | путь | `"REAL.log"` | Файл журнала: путь относительно папки `REAL.exe` или полный путь. Окно не примет пустой путь и символы `< > " \| ? *` |
| `maxFileSizeMb` | «Размер файла, МБ» | 1–1024 | `1` | Когда файл дорастает до этого размера, начинается новый |
| `maxFiles` | «Сколько файлов хранить» | 1–100 | `3` | Сколько файлов журнала хранить; самый старый удаляется, когда начинается новый |

Каждая строка файла начинается с даты, времени и уровня: `[2026-10-01 12:00:00.000] [info] …`.
Файл открывает «Диагностика → Открыть журнал» в строке меню (или «Файл журнала» в меню значка).
`--log-level <уровень>` задаёт уровень на один запуск.

## 10. Служебные поля

Два поля в начале файла, без комментариев. Менять их вручную не нужно.

| Ключ | Значение | Что делает |
|---|---|---|
| `configVersion` | `1` | Оформление файла. Файл с другим номером один раз перезаписывается в текущем оформлении: значения, которые программа знает, сохраняются, а ключи, которых она не знает, исчезают |
| `commentLanguage` | `"en"` или `"ru"` | Язык комментариев в файле. Если он отличается от языка программы, файл перезаписывается с комментариями на текущем языке, все значения сохраняются |
